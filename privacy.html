Privacy Policy

Last updated: 2026-10-06

What uploader accesses

  • youtube.upload: to upload videos, titles, descriptions and tags that the user selects to the user's own YouTube channel.
  • youtube.readonly: only to display the connected channel's name so the user can confirm the destination channel.

How data is stored and shared

  • The OAuth token is stored only on the user's own computer. It is never sent to any server other than Google.
  • uploader has no server. It does not collect, sell, or share any personal data with third parties.
  • Videos and metadata are sent only to YouTube, at the user's request.

Data deletion

uploader does not keep any copy of YouTube data. The only stored item is the OAuth token on the user's own computer. To delete it, remove the token file (youtube_token.json) from the program folder, or revoke access as described below; Google then deletes the authorization. Upload records kept next to the user's own video files (uploaded.json) contain only video IDs and titles and can be deleted at any time by deleting that file.

Revoking access

You can revoke uploader's access at any time at Google Account permissions. Deleting the local token file also removes access from the computer.

Google and YouTube terms

uploader uses YouTube API Services. By using uploader you agree to the YouTube Terms of Service. See also the Google Privacy Policy.
